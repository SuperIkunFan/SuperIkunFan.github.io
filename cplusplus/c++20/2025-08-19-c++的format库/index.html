    format库

    一、前言

    c++20之前，c++在输出字符串时常常使用printf或者是流式操作符这两种方式进行字符串输出。

    1.1 printf的缺点

    printf需要程序员自己选择格式化的方式，需要用户自己指定当前数据类型，从而在运行时进行格式化。由于这个特性，它带来了不便于维护的缺点：

    1. 类型不匹配导致未定义行为（Undefined Behavior）
      printf 完全依赖程序员手动指定格式化符（如 %d, %f, %s），但不检查实际传入参数的类型是否匹配。

    2. 缺乏编译时检查
      由于 printf 是 可变参数函数（variadic function），编译器无法在编译期验证格式字符串与参数的匹配性。

    3. 类型选择错误常见且隐蔽
      C++ 中类型丰富（如 size_t, ptrdiff_t, long long, uint32_t），但 printf 没有统一的格式化规则。
      这导致平台维护性差。

    4. 字符串安全问题
      printf 对字符串处理不安全，尤其是当格式字符串来自用户输入时：

      char* user_input = "%s%s%s%s%s%s";  // 恶意输入
printf(user_input);  // ❌ 格式化字符串攻击！会读取栈上随机数据
      这曾是历史上著名的安全漏洞来源（如缓冲区溢出攻击）。

    1.2 流式操作符

    由于printf有这些缺点，c++提出使用流式运算符，通过函数重载的方式自动匹配对应的格式化函数。但是流式运算符会造成整体输出的格式化字符串分散，难以从整体看出所要格式的字符内容是是什么。尤其是在一次格式化时有多个参数一同输出时更为严重。

    #include <iostream>
#include <iomanip>

struct User {
    std::string name;
    int age;
    double salary;
    std::size_t login_count;
};

User user{"张三", 28, 85000.0, 153};

std::cout << "用户: " << user.name
          << " (" << user.age << "岁), 年薪: "
          << std::fixed << std::setprecision(2) << user.salary
          << "元, 登录次数: " << user.login_count << "次"
          << std::endl;

    1.3 format库

    由于以上两种方式都没有那么舒服，而 Python 的 f-string（格式化字符串字面量） 提供了一种更直观、更优雅的解决方案.

    name = "张三"
age = 28
salary = 85000.0

# ✅ f-string：直观、集中、安全
print(f"用户: {name} ({age}岁), 年薪: {salary:,.2f}元")

    f-string 的优势：

    1. 格式完全集中
      整个输出模板清晰可见，无需拼接。

    2. 变量直接嵌入
      {name}、{age} 直接写在字符串中，无需额外参数列表。

    3. 支持格式化语法
      {salary:,.2f} 支持千位分隔、精度控制，类似 std::format。

    因此，c++20提出了format库。

    二、格式化字符串

    format库与python的解决方案有很大的相似性。都是给定一个格式化的字符串内容，不同的是python是将变量直接在格式化字符串中放置，而c++是将这些变量当作参数传入格式化函数。

    std::string s = std::format("name is {}.\r\n", "yy");

    这一对花括号{}就类似于printf中的占位符。而printf中是可以选择特定的格式化方式，format库是在一对花括号内添加一定的内容来指定格式化的方式。

    "{paraIndex:paraForm}"

    格式化整体上呈现如上，在冒号之前的是参数索引paraIndex，它表示的将后面填入的哪一个参数放入到这个位置。

    后面的paraForm表示如何将这个变量转化为字符串的哪种形式。

    2.1 参数顺序指定

    std::format 库支持显式指定参数索引，这意味着你可以完全控制参数在格式字符串中的使用顺序，甚至可以重复使用同一个参数。这比 printf 的位置参数（如 %2$d）更加灵活和直观。

    1. 显式参数索引
      在格式说明符中，冒号 :之前的部分可以是一个数字，表示使用 std::format 函数参数列表中的第几个参数（从 0 开始计数）。 
      #include <format>
#include <iostream>

int main() {
    std::string name = "Alice";
    int age = 30;
    double height = 1.65;

    // 按照参数索引 0, 1, 2 的顺序使用
    std::cout << std::format("{0}, {1}, {2}\n", name, age, height);
    // 输出: Alice, 30, 1.65

    // 乱序使用参数：先用索引 2，再用 0，最后用 1
    std::cout << std::format("身高: {2}m, 名字: {0}, 年龄: {1}\n", name, age, height);
    // 输出: 身高: 1.65m, 名字: Alice, 年龄: 30

    // 重复使用同一个参数：索引 0 被用了两次
    std::cout << std::format("用户 {0} 的名字是 {0}。\n", name);
    // 输出: 用户 Alice 的名字是 Alice。
}
    2. 混合使用位置参数和自动递增参数
      • 你可以在同一个格式字符串中混合使用显式索引和自动递增的参数。但一旦使用了显式索引，后续的所有参数都必须使用显式索引。 
        // ✅ 正确：全部使用自动递增（隐式索引）
std::format("{}, {}, {}", "a", "b", "c");

// ✅ 正确：全部使用显式索引
std::format("{2}, {0}, {1}", "a", "b", "c"); // 输出: c, a, b

// ❌ 错误！混合使用会编译失败
// std::format("{}, {1}, {}", "a", "b", "c"); // 错误！不能先用隐式再用显式
      • 规则总结：
        • 如果格式说明符中没有指定索引（如 {}），则按参数出现的顺序自动分配。
        • 如果格式说明符中有指定索引（如 {0}），则所有参数都必须使用显式索引。
        • 显式索引允许乱序和重复使用参数。

    2.2 格式化形式指定

    首先看格式化形式的完全体形式为：

    [[fill]align][sign][#][0][width][,][.precision][format]

    1. 对齐（Alignment）与填充（Fill）
      这部分控制输出的宽度和文本在该宽度内的对齐方式。

      • < (左对齐): 内容靠左，填充在右侧。 
        std::format("{:<10}", "Hi"); // 输出 "Hi        "
      • > (右对齐): 内容靠右，填充在左侧。 
        std::format("{:>10}", "Hi"); // 输出 "        Hi"
      • ^ (居中对齐): 内容居中，填充在两侧。 
        std::format("{:^10}", "Hi"); // 输出 "    Hi    "
      • = (符号后填充): 仅用于数字。填充字符（通常是空格或0）放在符号（+, -, ）之后，数字之前。这在对齐带符号的数字时非常有用。 
        std::format("{:=+5}", 42);  // 输出 "+  42"
std::format("{:=+05}", 42); // 输出 "+0042" (fill='0', width=5)
      • 填充字符 (fill): 可以在对齐标志前指定一个字符作为填充字符。如果省略，默认是空格。 
        std::format("{:0>5}", 42); // 输出 "00042", 用 '0' 填充，右对齐
std::format("{:*>10}", "Hi"); // 输出 "********Hi", 用 '*' 填充，右对齐

    2. 符号（Sign）
      控制数值的符号显示。

      • + 正数也显示 + 号。 
        std::format("{:+}", 42);  // 输出 "+42"
std::format("{:+}", -42); // 输出 "-42"

      • -(默认): 负数显示 - 号，正数不显示符号。 

        std::format("{:-}", 42);  // 输出 "42"
std::format("{:-}", -42); // 输出 "-42"

      • (空格): 负数显示 - 号，正数前面加一个空格。 

        std::format("{: }", 42);  // 输出 " 42"
std::format("{: }", -42); // 输出 "-42"

    3. 替代形式（Alternative Form）#
      对于某些类型，# 标志启用“替代形式”。

      • 整数 (b, o, x, X): 在输出前添加进制前缀。 
        std::format("{:#x}", 255); // 输出 "0xff"
std::format("{:#X}", 255); // 输出 "0xFF"
std::format("{:#o}", 64);  // 输出 "064"
std::format("{:#b}", 5);   // 输出 "0b101"
      • 浮点数 (a, A, e, E, f, F, g, G): 即使没有小数部分，也强制显示小数点。 
        std::format("{:#.0f}", 42.0); // 输出 "42." (而不是 "42")
std::format("{:#g}", 42.0);   // 输出 "42." (而不是 "42")

    4. 宽度（Width）与精度（Precision）

      • width: 一个整数，指定输出的最小字符宽度。如果内容长度小于此值，则用填充字符补齐。 
        std::format("{:8}", "Hi"); // 输出 "      Hi" (总宽8字符)
      • .precision: 以 . 开头，后跟一个整数，其含义取决于类型：
        • 字符串: 指定最大输出的字符数（截断）。
          std::format("{:.3}", "Hello"); // 输出 "Hel"
        • 浮点数: 指定小数点后的位数（对于 f, e, E）或总的有效数字位数（对于 g, G）。 
          std::format("{:.2f}", 3.14159); // 输出 "3.14"
std::format("{:.3g}", 1234.56);  // 输出 "1.23e+03"
        • 整数 (b, o, x, X): 指定最小的数字位数，不足则用前导零填充。 
          std::format("{:06x}", 255); // 输出 "0000ff"

    5. 千位分隔符 ,
      在支持的类型（整数和浮点数）的整数部分插入千位分隔符（通常是逗号）。 

          std::format("{:,}", 1234567);     // 输出 "1,234,567"
    std::format("{:,.2f}", 1234.567); // 输出 "1,234.57"

    6. 格式类型（Format Type）
      这是最核心的部分，决定了数据的表示方式。

      • d, i: 十进制有符号整数。
      • u: 十进制无符号整数。
      • o: 八进制整数。
      • x: 十六进制整数（小写字母 a-f）。
      • X: 十六进制整数（大写字母 A-F）。
      • b: 二进制整数（小写字母）。
      • B: 二进制整数（大写字母）。
      • c: 字符。
        std::format("{:c}", 65); // 输出 "A"
      • s: 字符串（默认，可省略）。
      • a, A: 浮点数的十六进制表示（a 小写，A 大写）。
      • e, E: 科学计数法（e 小写，E 大写）。 
        std::format("{:.2e}", 1234.56); // 输出 "1.23e+03"
      • f, F: 定点表示法（f 小写，F 大写）。 
        std::format("{:.2f}", 1234.56); // 输出 "1234.56"
      • g, G: 通用格式。根据数值大小和精度，自动选择 f 或 e（g 小写，G 大写）。
      • %: 百分比。将数值乘以100并添加 % 符号。 
        std::format("{:.1%}", 0.123); // 输出 "12.3%"

    三、自定义类型

    想要实现格式化自定义类型的话，c++标准要求对自定义类实现formatter。formatter是一个模板类，通过将自定义类型特化的方式来实现格式化输出。

    template< class T, class CharType = char >
struct formatter {
using CharT = CharType;
using Arg = T;

template<class ParseContext>
constexpr ParseContext::iterator formatter::parse(ParseContext& ctx)

template<class FmtContext>
FmtContext::iterator format(Arg s, FmtContext& ctx) const;
};

    其中需要特化实现两个成员函数parse和format两个成员函数，其中parse和format声明为模板成员函数是为了支持string和wstring。

    当我们要为自定义类型定义个性化的格式化输出时，std::format 的工作流程如下：

    1. 格式字符串在编译期传递给 parse 函数。
    2. parse 函数解析并存储格式选项。
    3. format 函数执行实际的格式化。

    3.1 解析成员函数parse

    首先，parse成员函数是编译期执行的，它的语义学是在编译器就将{}内部的格式化要求读取到实例化对象中，即通过{}来读取用户想要进行何种格式化。

    template<class ParseContext>
constexpr ParseContext::iterator formatter::parse(ParseContext& ctx)

    成员函数parse的入参是一个模板类，先看它的模板声明：

    template< class CharT >
std::basic_format_parse_context {
public:
    using char_type = CharT;
    using iterator  = std::basic_string_view<CharT>::const_iterator;
    using const_iterator = std::basic_string_view<CharT>::const_iterator;

    constexpr explicit basic_format_parse_context( std::basic_string_view<CharT> fmt,
                            std::size_t num_args = 0 ) noexcept;

    constexpr explicit basic_format_parse_context( const basic_format_parse_context& ) = delete;

    constexpr const_iterator begin() const noexcept;
    constexpr const_iterator end() const noexcept;

    /*
    ... 其他成员函数
    */
}

    可以看到它主要是传入了一个字符串视图，并且通过begin和end函数来获取对象的实例化长度。

    那么，这个字符串长度从哪里到哪里呢？在gcc13以上它传入的字符串视图是从第二章介绍的paraForm开始的，直至到格式化字符串末尾。

    const char * f = "{:abcde}\r\n";

    如上所示，它是从字符a开始，直到字符'\0'为止。而并未到下一个}为止。从而我们就知道了parse函数所提供的参数中所拥有的内容。

    parse的要求如下：

    1. 如果格式说明符（format-spec）不存在或为空，那么要么 parse_ctx.begin() == parse_ctx.end()，要么 *parse_ctx.begin() == '}'。
    2. parse要求不能有运行时要求。

    因而，是否对用户的形式相应是由提供者决定的。比如可以选择任意形式都输出同一个格式：

    struct myclass {

};

template<>
struct std::formatter<MyType> {
    constexpr auto parse(auto& ctx) {
        auto it = ctx.begin();
        auto end = ctx.end();

        do {
            if (it == end || *it == '}') {
                return it;
            }
        }while(1);

        return ctx.end();
    }
private:
    char format_ = 'd'; // 默认格式
};

    这样无论用户怎么填，他都是输出以d的格式输出的。

    那么让用户在编译期就知道不支持类型呢？cppreference使用的是抛运行期异常：

    #include <format>
#include <string_view>
#include <stdexcept>

struct QuotableString : std::string_view {};

template<>
struct std::formatter<QuotableString> {
    bool quoted = false;

    constexpr auto parse(auto& ctx) {
        auto it = ctx.begin();
        if (it == ctx.end()) return it;
        if (*it == '#') {
            quoted = true;
            ++it;
            if (it != ctx.end() && *it != '}') // 只允许 '#' 后紧跟 '}'
                throw std::format_error("invalid format");
        } else if (*it != '}') {
            throw std::format_error("invalid format");
        }
        return it;
    }

    auto format(QuotableString s, auto& ctx) const {
        if (quoted)
            return std::format_to(ctx.out(), "\"{}\"", s); // 简化：直接加引号
        else
            return std::format_to(ctx.out(), "{}", s);
    }
};

int main(){
    std::format("{:#}", QuotableString{}); // ok;
    std::format("{:#11}", QuotableString{}); // error;
    return 0;
}

    3.2 格式化字符串format

    format就是如何根据parse解析到的格式来格式化输出内容。先看它的函数声明：

    template<class FmtContext>
FmtContext::iterator format(Arg s, FmtContext& ctx) const

    第一个参数就是特化时所使用的模板参数，第二个就是所谓的输出字符串，可以把它理解为字符串容器。

    那么这个FmtContext类一般为std::basic_format_parse_context。先看它的类声明:

    template<class OutputIt, class CharT >
class basic_format_context {
public:
using char_type = CharT;
using iterator  = OutputIt;


basic_format_context() = delete;
basic_format_context & operator=(const basic_format_context& ) = delete;

/*重要函数*/
iterator out();
};

    其中主要暴露了out函数，它返回指向输出缓冲区的迭代器。该结果由存储的迭代器通过移动构造得到。

    知道了它之后，我们就可以这样调用std::formmat_to函数将变量值格式化到缓冲区中。以std::format_string为例，看看std::formmat_to的函数声明。

    template< class OutputIt, class... Args >
OutputIt format_to( OutputIt out,
                    std::format_string<Args...> fmt, Args&&... args );

    为什么建议使用它呢？c++标准库已经把一些常见的类和基础类型已经有了特化版本的format实现了，一般来说，自定义类型是基础类型和库类型的一种堆叠，那么利用这个就可以完成字符串的格式化。

    如下例子：

    struct mystruct{
    int a;
    int b;
};

template<>
struct std::formatter<mystruct> {
    bool print_a = true;
    bool print_b = true;
    using Arg = mystruct;

constexpr auto parse(auto& ctx) {
        auto it = ctx.begin();
        auto end = ctx.end();

        if (it == end || *it == '}') {
            return it; // 使用默认值：都打印
        }

        print_a = false;
        print_b = false;

        for (; it != end && *it != '}'; ++it) {
            switch (*it) {
                case 'a':
                    print_a = true;
                    break;
                case 'b':
                    print_b = true;
                    break;
                default:
                    break;
            }
        }

        return it;
    }

    auto format(const Arg & s, auto& ctx) const {
        auto iterator = ctx.out();
        if (print_a) {
            iterator = std::format_to(iterator, "a = {} ", s.a);
        }

        if (print_b) {
            iterator = std::format_to(iterator, "b = {} ", s.b);
        }
        return iterator;
    }
};

    综上，可以把传入的参数当作是一个使用std::back_inserter构造出来的输出迭代器。

    3.3 验证parse传入的字符串

    #include <format>
#include <array>
#include <cstddef>

struct mystruct {
    int a;
    double b;
};

template<>
struct std::formatter<mystruct> {
    // 存储前4个字符，不足用 '\0' 填充
    std::array<char, 4> prefix{'\0', '\0', '\0', '\0'};
    size_t count = 0;  // 实际字符数

    // 解析格式字符串中的内容（在 {} 内）
    constexpr auto parse(auto& ctx) {
        auto it = ctx.begin();
        auto end = ctx.end();

        // 遍历最多4个字符，直到 '}' 或结束
        count = 0;
        while (it != end && *it != '}' && count < 4) {
            prefix[count++] = *it;
            ++it;
        }

        // 注意：返回的是最后一个解析位置（不包括 '}'）
        // 标准要求返回 '}' 前的位置，std::format 会自动处理 '}'
        return it;
    }

    // 格式化输出：直接打印记录的前4个字符
    auto format(const mystruct&, auto& ctx) const {
        auto out = ctx.out();

        // 输出实际记录的字符
        for (size_t i = 0; i < count; ++i) {
            *out++ = prefix[i];
        }

        return out;
    }
};

#include <iostream>

int main() {
    mystruct data{1, 2.0};

    std::cout << std::format("HELLO {}!", mystruct{}) << "\n";
    // 输出: HELLO !

    std::cout << std::format("Code: {ABC}", data) << "\n";
    // 输出: Code: ABC

    std::cout << std::format("Tag: {hello}", data) << "\n";
    // 输出: Tag: hell  （只取前4个）

    std::cout << std::format("Empty: {}", data) << "\n";
    // 输出: Empty: 
}
