    巴特沃斯滤波器

    1 前言

    根据前面的滤波器基础知识，可以考虑带有零点的滤波器，但是这样整体比较复杂，因此我们考虑的没有零点，仅有极点的滤波器。这种滤波器被称为全极点滤波器。

    在二阶低通滤波器基础知识中，我们知道可以根据不同的Q值来设计不同的滤波器。那么有一下三种：

    \[ \begin{align} Q < \frac{1} {\sqrt{2}} \quad \text{-- 贝塞尔型} \notag \\ Q = \frac{1} {\sqrt{2}} \quad \text{--巴特沃斯型} \notag \\ Q > \frac{1} {\sqrt{2}} \quad \text{--切比雪夫型} \notag \end{align} \]

    巴特沃斯滤波器最明显的特征是它的特征频率等于截止频率。它的通带平坦，没有起伏，过渡带下降速度一般。因为Q是个定值，所以巴特沃斯滤波器的电阻电容间的比例是唯一的。由于特性比较优秀，参数唯一，设计方便，巴特沃斯滤波器应用非常广泛。

    贝塞尔滤波器在特征频率处的幅值小于0.707，低通滤波器信号的幅值是随着频率增大越来越小的，所以贝塞尔滤波器的截止频率小于特征频率。贝塞尔滤波器的过渡带比巴特沃斯还要缓慢，看起来它没什么优点，在幅频特性上确实是这样，但贝塞尔滤波器的相频特性优秀，它的通带群延时是最低的，这意味着贝塞尔滤波器可以有效减小通带信号失真，这是它最大的优点。

    切比雪夫滤波器在特征频率处的幅值大于0.707，它可以是1甚至更大，它拥有最陡峭的过渡带。在通带内，切比雪夫滤波器具有隆起，且Q越大，隆起越大。

    本文主要涉及巴特沃斯滤波器，下文开始介绍巴特沃斯滤波器。

    2 巴特沃斯滤波器

    首先看巴特沃斯滤波器的一般表达式：

    \[ |H(j\omega)| = \frac{1}{\sqrt{1+\omega^{2n}}} \]

    或者是

    \[ H(j\omega)^2 = \frac{1}{1+\omega^{2n}} \]

    巴特沃斯滤波器幅值响应应满足： + 通带最大平台型：在\(\omega = 0\)处尽可能多阶导数为零。 + 截止频率归一化：在\(\omega = \omega_c\)时，\(|H(j\omega_c)|^2 = \frac{1}{2}\)。

    根据以上要求，我们来推导出巴特沃斯滤波器幅值平方响应的一般表达式

    \[ |H(j\omega)|^2 = \frac{1}{1 + f(\omega)} \]

    其中\(f(\omega)\)需要满足： 1. \(f(0) = 0\) 通带无衰减 2. \(f(\omega_c) = 1\),这样满足截止频率增益为\(\frac{1}{\sqrt{2}}\)。 3. \(f(\omega)\)随着\(\omega\)单调递增。

    因此，我们考虑函数形式为\(f(\omega)\)为\(\omega\)的偶次幂函数。考虑 $$ f(\omega) = (\frac{\omega}{\omega_c})^{2n} $$ 其中n为滤波器阶数。 针对第一点：1. 最大平坦性（Maximally Flat）的数学要求 巴特沃斯滤波器的核心目标是：在通带内\(\omega = 0\)附近实现幅频响应的最大平坦性，即尽可能多阶导数为零。 + 数学条件：
    若幅值平方响应\(|H(j\omega)|^2\)在\(\omega = 0\)处的泰勒展开为： $$ |H(j\omega)|^2 = 1 - c \omega^{2n} + 高阶项 $$
    要使得通带最平坦，需要消除高阶项(即\(c \omega^{2n}, c \omega^{4n}, \cdots, c \omega^{2n -1}\)) + 唯一解：
    满足此条件的函数形式为\(\frac{1}{1 + \omega^{2n}}\),其泰勒展开为：
    $$ \frac{1}{1 + \omega^{2n}} = 1 + c \omega^{2n} + c \omega^{4n} + \cdots + c \omega^{2n -1} $$
    所有高于\(2n\)阶的导数\(\omega_0\)处均为零，从而实现最大平坦性。

    针对第二点，要求在截止频率处满足-3dB的衰减，那么 + 归一化设计 (\(\omega_c = 1\)):
    直接要求\(|H(j1)|^2 = \frac{1}{1 + 2 ^ {2n}} = \frac{1}{2}\),他对任意阶n都是成立的。 + 非归一化形式：
    若截止频率为\(\omega_c\)，则形式为\(\frac{1} {1 + (\omega/\omega_c)^{2n}}\)，仍然满足幅值为\(|H(j\omega_c)|^2 = \frac{1}{2}\)。

    当前我们已经知道了巴特沃斯滤波器的幅值响应时所具有的一般形式了，那么怎么推导它的一般形式呢？

    2.1 求解巴特沃斯滤波器的极点

    根据前面的内容，当我们知道了归一化设计时的频率要求时，那么我们通过变量代换\(x = \frac{\omega}{\omega_c}\)带入到归一化后的滤波器中，就可以得到响应的参数了。那么如何根据归一化的幅值平方响应函数来求取极点呢？ 计算幅平公式时，已知\(s = \omega j\)，那么 $$ \begin{align} |H(s)|^2 = |H(s)| \times |H(-s)| = \frac{1} { 1 + (s/j)^{2n}} \end{align} $$ 则根据极点公式有 $$ \begin{align} 1 + (s/j)^{2n} = 0 \ \Rightarrow s^{2n} = -1 \times j ^{2n} \end{align} $$

    由于 $$ \begin{align} -1 = e^{j\pi(2k-1)} \ j = e ^ {j \pi / 2} \end{align} $$

    得到 $$ \begin{align} s^{2n} = e ^ {j \pi (2k - 1 + n)} \end{align} $$ 所以得到 $$ \begin{align} s_k = e ^ {\frac{j \pi} {2n} (2k - 1 + n)} \text{其中} k = 1, 2, 3 \cdots 2n \end{align} $$ 这个里面还包含了包含正版平面的极点，那么我们怎么确定哪些是呢？可以观察到，当k小于等于n时，此时 $$ 0 < \frac{2k-1}{2n} < 1 \ \Rightarrow 0.5 < \frac{2k-1 + n }{2n} < 1.5 \ \Rightarrow 0.5 \pi < \frac{ \pi (2k-1 + n) }{2n} < 1.5 \pi $$

    则它在负半轴。则可以得到该滤波器的传递函数为： $$ H(s) = \frac{1} {(s - s_1)(s - s_2) \cdots (s - s_n)} $$

    3 模拟滤波器离散化

    现在我们已经得到了巴特沃斯滤波器的一般表达式了，那么如何转化为数字滤波器呢？一般而言，我们使用双线性变换法将模拟滤波器的频率变换到数字滤波器中。已知z域和s域的关系式为\(z = e ^ {sT} \(，其中\)T\)是采样时间，但是这种方式会在成频谱混叠，至于为什么，我也不知道。。。

    3.1 双线性公式推导

    如果重写上面的式子，则有 $$ z = e ^ {sT} = \frac{e^{sT/2}}{e^{-sT/2}} $$ 将上面的式子在原点\(sT/2 = 0\)，进行泰勒展开，并去除高阶项，得到

    \[ \begin{align} z \approx \frac{1 + sT/2}{1 - sT/2} \notag \\ \Rightarrow s = \frac{2z -1}{T(z - 1)} \notag \end{align} \]

    那么为什么和一般推导出来的结果不太一样呢？如下式

    \[ s = \frac{2}{T}\frac{1 - z^{-1}}{1 + z^{-1}} \]

    这是因为，一般来说，z变换中，有两个算子，z和\(z^{-1}\)两个算子，分别对应时域中的超前和延迟操作

    1. z的作用：时域超前
      • 数学定义：
        若序列x[n]的z变换时X(z),则zX(z)对应的时域序列为x[n+1]，即右移或者超前一个采样周期
      • 物理意义： z表示超前算子，表示信号在时间轴上向前移动一步。常用来描述差分方程中的未来状态。

    2. \(z^{-1}\)的作用：时域延迟

      • 数学定义： \(z^{-1} X(z)\)对应的时域序列为x[n-1]，即左移或者延迟一个采样周期
      • \(z^{-1}\)是延迟算子（或单位延迟），表示信号在时间轴上向后移动一步。它是数字滤波器实现中的基本单元，对应硬件中的寄存器或存储单元

    3. 一般情况下，我们认为当前的输出是历史和当前的输入所决定的，而非未来的，即存在因果关系。因此在描述系统模型的差分方程中，常常使用\(z^{-1}\)算子来描述系统方程，如 $$ H(z) = \frac{b_0 + b_1 z^{-1} + \cdots + b_n z^{-n}}{1 + a_1 z^{-1} + \cdots + a_m z^{-m}} $$

    4. 频域解释

      • \(z = e^{j\omega}\)在单位圆上，而\(z^{-1} = e^{-j\omega}\)表示频率响应中的相位延迟，而z表示相位超前。
      • 幅值响应，\(|z^{-1}| = 1\),因此\(z^{-1}\)不改变信号幅值，仅影响相位。

    总结如下:

    算子 时域效果 频域效果 典型应用场景
    \(z\) 超前（右移） 相位超前 状态空间模型、预测控制
    \(z^{-1}\) 延迟（左移） 相位延迟 数字滤波器、差分方程实现

    根据上面的内容，我们需要的是历史数据，所以要分子分母共同除以z，以$ z^{-1}$算子的形式来表示双线性变换的形式，以便于我们实现数字滤波器。 由于分子和分母和s是线性关系，所以这个式子就叫双线性变换。分子一个线性变换，分母一个线性变换。

    3.2 离散截止频率和模拟截止频率的关系

    前面我们已经得到了双线性变换，那么经过双线性变换后，模拟截止频率\(f_a\)和数字截止频率\(f_d\)还是线性关系吗？可以利用拉普拉斯作用符s当作桥梁来推导：

    \[ \begin{align} s = j \omega_a = j \times 2 \pi \times f_a \end{align} \]
    \[ \begin{align} z = e ^{sT}, s = j\omega_d, \omega_d = 2 \pi f_d , T = 1/f_s\\ z = e ^{sT} = e ^{j 2 \pi \frac{f_d}{f_s}} \end{align} $$ 将这个模拟截止频率为$f_d$的z变换公式带入到双线性变换公式中可以得到： $$ s = 2f_s \frac{1 - z^{-1}}{1+z^{-1}} \\ = 2f_s \frac{1 - e ^{-j 2 \pi \frac{f_d}{f_s}}}{1 + e ^{-j 2 \pi \frac{f_d}{f_s}}} \\ = 2f_s \frac{- 1 + e ^{j 2 \pi \frac{f_d}{f_s}}}{1 + e ^{j 2 \pi \frac{f_d}{f_s}}} \\ = j2f_s tan(\frac{\pi f_d}{f_s}) \]

    再次借助s运算符，得

    \[ s = j 2 \pi f_a = j 2f_s tan(\frac{\pi f_d}{f_s}) \]

    从而得到了

    \[ f_a = \frac{f_s} {\pi} tan(\frac{\pi f_d}{f_s}) \]

    3.3 数字滤波器的设计的整体流程

    因为前面我们得到的是模拟滤波器的巴特沃斯滤波器表达式，那么我们需要将数字滤波器转化为模拟滤波器后，再带入到模拟滤波器中，然后通过双线性变换得到响应的离散系统实现，从而可以写成代码，再实际中运行。

    1. 利用公式\(f_a = \frac{f_s} {\pi} tan(\frac{\pi f_d}{f_s})\)得到模拟角频率\(\omega_a = 2 f_s tan(\frac{\pi f_d}{f_s})\)
    2. 由于前面得到的模拟滤波器是归一化后的，因此我们需要将\(s \rightarrow \frac{s}{w_a}\)，所以前两步得到的 \(\(s \rightarrow \frac{s}{w_a} = \frac{ 2f_s \frac{1-z^{-1}} {{1+z^{-1}}}}{2f_s tan(\frac{\pi f_d}{ f_s})} = \frac{\frac{1-z^{-1}} {{1+z^{-1}}}} {tan(\frac{\pi f_d}{ f_s})}\)\)
    3. 将第二步得到的经过双线性变化后的表达式s带入到归一化后的二阶巴特沃斯低通滤波器中 $$ H(s) = \frac{1} {s^2 + 1.414s + 1} $$
    \[ \LARGE = \frac{1} {(\frac{\frac{1-z^{-1}} {{1+z^{-1}}}} {\tan(\frac{\pi f_d}{ f_s})})^2 + 1.414(\frac{\frac{1-z^{-1}} {{1+z^{-1}}}} {\tan(\frac{\pi f_d}{ f_s})}) + 1} \]
    \[ \LARGE = \frac{(\tan(\frac{\pi f_d}{ f_s}))^2} {(\frac{1-z^{-1}} {{1+z^{-1}}} )^2 + 1.414(\frac{1-z^{-1}} {1 + z^{-1}} \times \tan(\frac{\pi f_d}{ f_s}) + (\tan(\frac{\pi f_d}{ f_s})))^2} \]

    令\(\tan(\frac{\pi f_d}{ f_s}) = \Omega_{new}\)，则有 $$ \Large = \frac {\Omega_{new}^2 (1 + z^{-1})^2} {(1 + z^{-1})^2 + 1.414 \Omega_{new} (1 + z^{-1}) (1 - z^{-1}) + \Omega_{new}^2 (1 + z^{-1})^2} $$

    化简出与\(z^{-1}\)有关的多项式

    \[ \Large = \frac {\Omega_{new}^2 + 2 \Omega_{new} z^{-1} + \Omega_{new}^2 z^{-2}} {1 - 2 z^{-1} + z^{-2} + 1.414 \Omega_{new} - 1.414 \Omega_{new} z^{-2} + \Omega_{new}^2 + 2 \Omega_{new}^2 z^{-1} + \Omega_{new}^2 z^{-1}} \]
    \[ \Large = \frac {\Omega_{new}^2 + 2 \Omega_{new} z^{-1} + \Omega_{new}^2 z^{-2}} {(1 + 1.414 \Omega_{new} + \Omega_{new}^2) + (2 \Omega_{new} ^ 2 -2)z^{-1} + (1 -1.414 \Omega_{new} + \Omega_{new}^2)z^{-2}} \]

    目前就把上面的滤波器离散化为与\(z^{-1}\)有关的公式了，令： $$ \begin{gather} B_0 = \Omega_{new}^2 \ B_1 = 2 \Omega_{new} \ B_2 = \Omega_{new}^2 \ c = 1 + 1.414 \Omega_{new} \ A_1 = (2 \Omega_{new} ^ 2 -2) \ A_2 = 1 -1.414 \Omega_{new} + \Omega_{new}^2 \end{gather} $$

    则原公式为

    \[ H(z) = \frac {B_0 + B_1 z^{-1} + B_2 z^{-2}} {c + A_1 z^{-1} + A_2 z^{-2}} \\ Y(z) = \left( \frac{B_0}{c} X(z) + \frac{B_1}{c} X(z) z^{-1} + \frac{B_2}{c} X(z) z^{-2} \right) - \left( \frac{A_1}{c} Y(z) z^{-1} + \frac{A_2}{c} Y(z) z^{-2} \right) \\ Y(z) = \frac{B_0}{c} X(z) + \frac{B_1}{c} X(z-1)+ \frac{B_2}{c} X(z-2) - \frac{A_1}{c} Y(z-1) + \frac{A_2}{c} Y(z-2) $$ 然后进行z逆变换 $$ y(n) = \frac{B_0}{c} x(n) + \frac{B_1}{c} x(n-1) + \frac{B_2}{c} x(n - 2) - \frac{A_1}{c} y(n-1) + \frac{A_2}{c} y(n-2) \]

    其中，下标n就代表当前值，下标n-1代表这个数是上个周期的值，n-2代表这个数延时了两周期。

    注意到，进行这个变换时，其单位是rad/s，因为在前面提到了，我们对模拟滤波器是使用弧度制。但是在离散滤波器设计中，常常采用的hz单位。但是由于之前提到与频率有关的参数就是\(\tan(\frac{\pi f_d}{ f_s}) = \Omega_{new}\)，因此只要保证两者的度量是一致就可以。由于我们使用传感器采样时常常使用的是一秒钟采样多少次，所以数字截止频率使用的是hz单位。

    4 使用python的滤波器设计

    在python的滤波器中，可以使用scipy.signal模块进行滤波器设计，对于butterworth滤波器而言，主要使用的三个函数 

    signal.butter
signal.freqs
signal.freqz
    第一个是根据截止频率返回对应的传递函数参数，第二个是对模拟滤波器进行频域响应，第三个是离散滤波器进行频域响应。

    值得注意的是，模拟滤波器使用的是rad/s，而离散滤波器使用的是hz

    使用python.signal的滤波器示例代码 

    import numpy as np
import scipy.signal as signal
import matplotlib.pyplot as plt

# 参数设置
order = 2                  # 滤波器阶数 (二阶巴特沃斯)
wc_analog = 15             # 模拟截止频率 (rad/s)
fs = 100                   # 采样频率 (Hz)
signal_freq = 4 * np.pi    # 信号频率 (rad/s), 约12.57 rad/s (2Hz)

# 1. 设计模拟滤波器 (二阶巴特沃斯)
b_analog, a_analog = signal.butter(order, wc_analog, 'lowpass', analog=True)

# 2. 设计数字滤波器（带预畸变校正）
wc_digital = 2 * fs * np.tan(wc_analog / (2 * fs))  # 预畸变
wc_digital = wc_analog
b_digital, a_digital = signal.butter(order, wc_digital, 'lowpass', fs=fs)
print(f"分子{b_digital}，分母{a_digital}")


# 3. 生成频率响应数据（改进计算精度）
# 模拟滤波器频率响应
w_analog = np.logspace(np.log10(0.01), np.log10(100), 1000)  # 0.1到100 rad/s
_, h_analog = signal.freqs(b_analog, a_analog, worN=w_analog)

# 数字滤波器频率响应（避免高频段数值问题）
w_digital = np.linspace(0.01, fs/2, 1000) * 2 * np.pi  # 从0.01开始避免0频率
_, h_digital = signal.freqz(b_digital, a_digital, worN=w_digital, fs=fs)


# 4. 绘制频率响应对比图
plt.figure(figsize=(12, 8))

# 幅频响应（添加小偏移避免log(0)）
plt.subplot(2, 1, 1)
analog_mag = 20 * np.log10(np.abs(h_analog) + 1e-12)  # 防止log(0)
digital_mag = 20 * np.log10(np.abs(h_digital) + 1e-12)

plt.semilogx(w_analog, analog_mag, 
            label=f'Analog Butterworth (fc={wc_analog} rad/s)')
plt.semilogx(w_digital, digital_mag, 
            '--', linewidth=2, label=f'Digital Butterworth (fs={fs} Hz)')

# 标记关键频率
plt.axvline(wc_analog, color='r', linestyle=':', label='Cutoff Frequency')
plt.axvline(signal_freq, color='g', linestyle='-.', 
           label=f'Signal Freq ({signal_freq:.2f} rad/s)')

plt.title('2nd Order Butterworth Filter Frequency Response')
plt.xlabel('Frequency [rad/s]')
plt.ylabel('Magnitude [dB]')
